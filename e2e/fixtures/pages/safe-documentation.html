Authentication

All API requests require authentication. The API supports two authentication methods: API keys for server-to-server communication and OAuth 2.0 for user-delegated access. Choose the method that best fits your integration pattern.

API Keys

API keys provide the simplest authentication method. Include your key in the Authorization header of every request:

curl -H "Authorization: Bearer sk_live_abc123..." \
     https://api.example.com/v1/users

Important: API keys carry full account privileges. Never expose them in client-side code, public repositories, or browser requests. Store keys in environment variables or a secrets manager.

OAuth 2.0

For applications that act on behalf of users, implement the OAuth 2.0 authorization code flow. This grants your app scoped access without exposing the user's credentials.

Authorization Flow

  1. Redirect the user to the authorization URL with your client_id and requested scope
  2. The user grants or denies permission
  3. On approval, the user is redirected to your redirect_uri with an authorization code
  4. Exchange the code for an access token via the token endpoint
POST /oauth/token
Content-Type: application/x-www-form-urlencoded

grant_type=authorization_code
&code=AUTH_CODE_HERE
&redirect_uri=https://yourapp.com/callback
&client_id=YOUR_CLIENT_ID
&client_secret=YOUR_CLIENT_SECRET

Token Management

Access tokens expire after 1 hour. Use the refresh token to obtain a new access token without requiring the user to re-authorize:

POST /oauth/token
Content-Type: application/x-www-form-urlencoded

grant_type=refresh_token
&refresh_token=REFRESH_TOKEN_HERE
&client_id=YOUR_CLIENT_ID

Refresh tokens are valid for 30 days. After expiry, the user must re-authorize through the full OAuth flow.

Rate Limits

API requests are rate-limited per authentication credential:

  • API Keys: 1,000 requests per minute
  • OAuth Tokens: 500 requests per minute per user

When you exceed the limit, the API returns 429 Too Many Requests with a Retry-After header indicating when you can resume.

Code Examples

Python

import requests

headers = {"Authorization": "Bearer sk_live_abc123..."}
response = requests.get("https://api.example.com/v1/users", headers=headers)
print(response.json())

JavaScript

const response = await fetch("https://api.example.com/v1/users", {
  headers: { Authorization: "Bearer sk_live_abc123..." }
});
const data = await response.json();
console.log(data);
